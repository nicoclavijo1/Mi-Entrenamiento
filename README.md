# Mi entrenamiento

App personal de rutinas de ejercicio, con el método Kaizen: cada serie que registras se vuelve tu tope y la próxima vez solo puedes igualarlo o superarlo.

- Rutinas de martes, miércoles, jueves, sábado y domingo
- Registro de series y repeticiones por ejercicio
- Calendario con chulo o equis según si se hizo la rutina
- Resumen del entrenamiento anterior contra el de hoy
- Modo claro y oscuro
- Se instala en el celular como aplicación

Los datos se guardan en el propio dispositivo. Para pasarlos a otro, en Ajustes → Tus datos hay un código para copiar y pegar.
